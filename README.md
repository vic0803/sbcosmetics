# Sophia Belinska Cosmetics — Design Prototype

Статичний прототип вітрини (HTML/CSS/JS), без інтеграцій. Для затвердження дизайну та мобільного вигляду перед розробкою на Next.js.

Static storefront prototype (HTML/CSS/JS), no integrations. For approving the design and mobile layout before Next.js development.

## Сторінки / Pages
- `index.html` — головна з hero день/ніч / home with day/night hero
- `catalog.html` — каталог з фільтрами / catalog with filters
- `product.html` — картка товару / product detail

## Особливості / Features
- Двомовність UA/EN (перемикач у шапці) / UA–EN language switch
- Mobile-first, чорно-золотий люкс-дизайн / black-gold luxury design
- Анімація hero день→ніч при скролі / day→night hero on scroll
- Мок-кошик, акордеон, варіанти товару / mock cart, accordion, variants

## Запуск / Run
Відкрийте `index.html` у браузері / Open `index.html` in a browser.

> Прототип. Оплата, доставка, CRM, авторизація — додаються пізніше.
> Prototype only. Payment, delivery, CRM, auth come later.
